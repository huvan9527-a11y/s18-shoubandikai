# S18 OPP3 · 20万元 GitHub Actions 模拟仓

使用此前认可的 `S18_OPP3_execution(1).py`（OPP3 v2.0 执行加固版）规则。
初始资金 **200,000 元**，独立账本，最多持有两只。默认单槽资金上限为账户权益的50%，实际金额还受成交额、现金、股数和手续费约束。

## 先完成行情配置

目前代码和空仓账本已就绪，**没有真实行情运行结果，也没有回测收益**。

1. 打开本仓库 **Settings → Secrets and variables → Actions → New repository secret**。
2. 添加 `JQ_USERNAME` 和 `JQ_PASSWORD`，分别为聚宽账号和密码。不要写入代码或公开仓库。
3. 账号必须有 **JQData 的当日日线、历史指数成分、ST状态、至少61个交易日日线、当日1分钟数据**权限。聚宽网页回测可用，不代表同账号自动拥有这些SDK权限；试用/购买及额度以聚宽为准。
4. 打开 **Actions → S18 20万元模拟仓 → Run workflow**。若 Actions 被禁用，先启用。工作流拥有 `contents: write`；若组织策略禁止写入，需允许该权限。

行情 SDK 官方说明：[JoinQuant/jqdatasdk](https://github.com/JoinQuant/jqdatasdk)。缺凭据或数据过期时不会用日K估计分钟成交。

## 自动运行与查看结果

- 工作日北京时间 **16:23** 运行，**18:23** 再尝试。GitHub 定时启动可能延迟。
- 收盘后读取当天真实1分钟行情，按当时可知的信息逐分钟模拟；不会在16点用当天开盘价直接记为买入。
- 启动日期为 **2026-10-08**。只处理交易所交易日；若当天休市，从之后首个交易日开始。
- 错过运行后按日期补跑；同一天重跑不会重复交易。账本单任务串行运行，状态自动提交回 `main`。
- 每次运行页面有账户摘要，也可下载报告 artifact。查看：
  - [最新摘要](outputs/latest.md)
  - [持仓表](outputs/holdings.csv)
  - [逐笔模拟成交](logs/trades.csv)
  - [每日净值](logs/equity.csv)
  - [候选、委托、未成交和错误状态](outputs/latest.json)

不发送实盘委托。公开仓库中的模拟持仓、交易记录和净值会公开。

## 保留的 S18 规则

股票池：昨日中证1000成分（`000852.XSHG`），剔除ST/退市、上市不足250自然日、61日历史不完整/停牌股票；昨日成交额至少1亿元。

| 优先级 | 组件 | 个股条件 | 开盘及买入时低开区间 | 市场条件 |
|---|---|---|---|---|
| 1 | FB_dip | 昨日首板、前日价格低于之前60日收盘中位数、非一字首板、10%板 | −7%～−2% | 指数低于MA20且跌停比例<3% |
| 2 | LB | 昨日连续涨停≥2天 | −4%～−2% | 跌停比例<3% |
| 3 | DEEP | 昨日既非涨停也非跌停 | −9%～−3% | 冰点且连续冰点≥2天或指数偏离MA20≤−4% |

冰点：昨日涨停股当日平均溢价≤−1%，或跌停比例≥1%；使用每个历史日期当时的指数成分预热40个交易日。

- 买入窗口 **9:31—9:35**，同组件按低开更深、股票代码排序；当天最多选中两只，每只最多两次买单，部分成交后不补仓。
- 价格≤190元；当前价仍在低开区间；追价不超过开盘+0.3%；排除距跌停≤0.5%、涨停和疑似除权日。
- 单笔金额不超过昨日成交额0.1%、上一完整分钟成交额10%；预留1%现金。
- 买入后 **下一交易日14:50—14:56** 退出，未卖出持仓以后交易日继续退出；T+1、停牌和跌停限制保留。
- 没有额外增加5%/6%止损或改为三天持仓；以该执行版为准。

## 成交模型与差异

这是**分钟级模拟成交假设**，不能证明真实成交、盘口排队或收益可复现；需要重新验证，不能继承原策略收益。

1. 以已完成分钟收盘价提交限价单，**仅后续分钟**撮合。9:31没有当日9:30完整连续竞价bar时跳过，通常最早9:32提交、9:33模拟成交。
2. 买入要求后续分钟最低价**低于**限价，保守按限价记成交；仅触价不算成交。单分钟成交量和成交额均限制参与率10%；未成交买单一分钟后失效，部分成交撤余单。
3. 卖出限价为现价下方0.5%、不低于跌停价。要求后续分钟最高价**高于**限价；一字跌停不成交。按下一分钟开盘下调0.1%的价格（且不低于限价）估算卖出，每票每天最多5次卖单。14:56提交的卖单至14:57撮合，然后日终撤单；次日继续。相比平台异步委托，这是离散分钟撮合近似。
4. 佣金每边 **0.025%**、最低5元；卖出税 **0.05%**。没有额外加入万三或其他费用。原版聚宽 `PriceRelatedSlippage(0.002)` 改为上述显式撮合规则：买入用限价的保守成本，卖出开盘下调0.1%；不能称为与聚宽引擎完全等价。
5. 不用全天成交额限制早盘下单，不用后续分钟来决定当前委托；当日收盘只用于日终估值。后续分钟只用于订单模拟撮合。
6. 数据准备失败暂停新增，旧持仓独立退出；旧持仓退出行情缺失则停止该日并保留最后成功账本。持仓除权/分红因子变化时停止更新，要求核对公司行为，避免无声算错收益。

`state/account.json` 是唯一权威账本，包含成交、净值、冰点缓存及逐日事件。CSV是导出，不用于推算账户；不要删除账本或手动改初始资金。
