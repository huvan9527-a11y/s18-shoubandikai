# S18 OPP3 · A/B独立模拟账户

本仓库使用公开行情运行模拟账户，不接券商实盘。股票池保留中证1000，每仓初始资金20万元、最多持有2只、每天最多新增2只；A/B不共用资金和持仓。

## 当前买卖规则

定义T为低开信号出现的交易日；个股条件、市场温度和昨收均仅使用T前一交易日及以前数据。

|组件|优先级|T日开盘涨跌幅|个股条件|市场条件|
|---|---:|---|---|---|
|FB_dip|1|−7%～−2%|昨日首板、非一字、10%板，前日价格低于此前60日收盘中位数|指数低于MA20且跌停比例<3%|
|LB|2|−4%～−2%|昨日连续涨停≥2天|跌停比例<3%|
|DEEP|3|**−7%～−3%**|昨日既非涨停也非跌停|冰点且（连续冰点≥2天或指数偏离MA20≤−4%）|

冰点：昨日涨停股当日平均溢价≤−1%，或跌停比例≥1%。剔除ST/退市、上市不足250自然日、历史不足、昨日停牌；昨日成交额至少1亿元。保留当前中证1000成分快照口径，不额外改为主板池。优先级后按低开更深、代码排序。

|账户|买入|卖出|
|---|---|---|
|A|T日09:30开盘价已知后，核验当日行情，按开盘价模拟成交|T+1交易日收盘价|
|B|取T日已确认低开信号前2只，T+1交易日按开盘价模拟成交，不再次要求低开|T+2交易日收盘价，即B买入后的下一交易日|

买入限制：价格≤190元、不买涨停或跌停开盘、不买当前ST/退市；A另保留距跌停0.5%的原过滤。单股预算≤权益50%、可用现金99%、信号依据日成交额0.1%，按交易单位取整。开盘价和收盘价为模拟成交价格假设，不再用分钟成交量限制、追价或下一分钟撮合。佣金万2.5、最低5元、卖出印花税万5；不额外加减开收盘价格滑点。

停牌或收盘跌停的待卖持仓顺延；缺少目标日收盘价明确失败，不伪造成交。买卖记录先保存再推送；推送失败重跑只重试通知，同一时段不重复交易。

## 自动流程（北京时间）

1. 工作日08:00计划启动，09:15检查上一交易日收盘报告。
2. 09:26保留竞价候选提醒，提醒不代表成交。
3. 09:30:03起核验腾讯当日开盘行情，在09:30—09:35窗口内完成A/B开盘价模拟记账并发送成交确认。行情失败在窗口内重试；超过窗口不补造买入。GitHub排队可能导致错过窗口，不能保证09:30准时。
4. 16:23、18:23计划盘后运行：**先按当日已完成日线处理A/B应卖持仓和估值，再扫描最近两交易日、生成下一交易日候选**。卖出不依赖分钟源，也不依赖本次候选扫描成功。收盘价在盘后确认并记账，不冒称15:00已实时发单。

成交推送使用现有`SERVERCHAN_SENDKEY`（兼容原别名）。未配置或服务失败会明确报错；成交已保存后重跑不会重复买卖。09:26提醒失败不阻止09:30模拟交易。

## 账本与报告

- `state/daily_accounts.json`：新流程唯一权威A/B账本，含成交、时段去重、推送状态。
- `outputs/latest.md` / `.json`：两仓现金、权益和持仓。
- `logs/trades-A.csv`、`logs/trades-B.csv`：分仓成交；`logs/equity-A.csv`、`logs/equity-B.csv`：分仓净值。
- `outputs/holdings-A.csv`、`outputs/holdings-B.csv`：分仓持仓。
- `outputs/execution-日期-open.json` / `-close.json`：当次成交及未执行原因。
- `outputs/signals-日期.json`：当日历史开盘信号，以及依据当日收盘生成的`next_session`候选。

首次运行保留旧A仓现金、持仓和历史成交，B仓以20万元独立启动。旧仓历史缺失卖出不补造；遗留持仓在新流程首次盘后执行时按当前收盘价退出（停牌/跌停顺延）。旧`state/account.json`、旧成交和净值文件保留为迁移前档案；旧分钟撮合模块不再接入定时工作流。
