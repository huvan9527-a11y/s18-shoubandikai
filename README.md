# S18 OPP3 · 20万元 GitHub Actions 模拟仓

使用此前认可的 `S18_OPP3_execution(1).py`（OPP3 v2.0 执行加固版）规则。
初始资金 **200,000 元**，独立账本，最多持有两只。默认单槽资金上限为账户权益的50%，实际金额还受成交额、现金、股数和手续费约束。

## 公共行情版本（无需聚宽账号）

不再安装或调用 JQData，不需要 `JQ_USERNAME` / `JQ_PASSWORD`。

- 日线、成交额、成交量及复权因子：新浪公开行情，经 AKShare 的解码器解析；指数日线：腾讯。
- 中证1000成分：中证指数官方文件；备用新浪成分页必须去重后恰好1000只，否则失败。
- 原始1分钟OHLC、成交量与成交额：东财最近5个交易日；成交量由手换算为股。
- 定时运行仍为工作日北京时间16:23、18:23。先扫描最近两个已完成交易日，再处理独立模拟仓；不能保证定时任务准点启动。
- `outputs/signals-YYYY-MM-DD.json` / `.md` 区分前一日候选、开盘候选、分钟撮合买入与数据失败。2026-10-08、2026-10-09可用 `python -u -m src.scan --dates 2026-10-08 2026-10-09` 重扫。
- 不完整股票池/历史行情不能当成零信号；失败的空仓日期不推进账本日期，保留重扫机会。
- 每50只股票打印一次采集进度。公开接口有超时和重试；不将日线低点冒充分钟买入。

**口径限制：当前公共接口没有提供完整历史逐日成分及ST状态。历史扫描和由此生成的模拟仓均为公开数据参考口径，不能声称完全复现原聚宽版本。** 报告记录该限制及覆盖情况。当前名字中的ST/退市股会排除；历史ST变更和被调出成分无法完整还原。未来每次采集保存观察日成分快照，供核对。

20万元账本仍在 `state/account.json`，不重置初始资金。分钟源缺失时扫描报告保留开盘候选但没有已验证买入；工作流失败，不以缺失数据生成交易。已有持仓的退出数据缺失或发生公司行为则保留最后成功账本。

结果在Actions摘要、报告artifact，以及仓库 `outputs/`、`logs/` 中。所有成交均为撮合模型假设。

## 保留的 S18 规则

原策略目标股票池：昨日中证1000成分（公共数据版本的历史口径限制见上文）（`000852.XSHG`），剔除ST/退市、上市不足250自然日、61日历史不完整/停牌股票；昨日成交额至少1亿元。

| 优先级 | 组件 | 个股条件 | 开盘及买入时低开区间 | 市场条件 |
|---|---|---|---|---|
| 1 | FB_dip | 昨日首板、前日价格低于之前60日收盘中位数、非一字首板、10%板 | −7%～−2% | 指数低于MA20且跌停比例<3% |
| 2 | LB | 昨日连续涨停≥2天 | −4%～−2% | 跌停比例<3% |
| 3 | DEEP | 昨日既非涨停也非跌停 | −9%～−3% | 冰点且连续冰点≥2天或指数偏离MA20≤−4% |

冰点：昨日涨停股当日平均溢价≤−1%，或跌停比例≥1%；使用每个历史日期当时的指数成分预热40个交易日。

- 买入窗口 **9:31—9:35**，同组件按低开更深、股票代码排序；当天最多选中两只，每只最多两次买单，部分成交后不补仓。
- 价格≤190元；当前价仍在低开区间；追价不超过开盘+0.3%；排除距跌停≤0.5%、涨停和疑似除权日。
- 单笔金额不超过昨日成交额0.1%、上一完整分钟成交额10%；预留1%现金。
- 买入后 **下一交易日14:50—14:56** 退出，未卖出持仓以后交易日继续退出；T+1、停牌和跌停限制保留。
- 没有额外增加5%/6%止损或改为三天持仓；以该执行版为准。

## 成交模型与差异

这是**分钟级模拟成交假设**，不能证明真实成交、盘口排队或收益可复现；需要重新验证，不能继承原策略收益。

1. 以已完成分钟收盘价提交限价单，**仅后续分钟**撮合。9:31没有当日9:30完整连续竞价bar时跳过，通常最早9:32提交、9:33模拟成交。
2. 买入要求后续分钟最低价**低于**限价，保守按限价记成交；仅触价不算成交。单分钟成交量和成交额均限制参与率10%；未成交买单一分钟后失效，部分成交撤余单。
3. 卖出限价为现价下方0.5%、不低于跌停价。要求后续分钟最高价**高于**限价；一字跌停不成交。按下一分钟开盘下调0.1%的价格（且不低于限价）估算卖出，每票每天最多5次卖单。14:56提交的卖单至14:57撮合，然后日终撤单；次日继续。相比平台异步委托，这是离散分钟撮合近似。
4. 佣金每边 **0.025%**、最低5元；卖出税 **0.05%**。没有额外加入万三或其他费用。原版引擎 `PriceRelatedSlippage(0.002)` 改为上述显式撮合规则：买入用限价的保守成本，卖出开盘下调0.1%；不能称为与聚宽引擎完全等价。
5. 不用全天成交额限制早盘下单，不用后续分钟来决定当前委托；当日收盘只用于日终估值。后续分钟只用于订单模拟撮合。
6. 数据准备失败暂停新增，旧持仓独立退出；旧持仓退出行情缺失则停止该日并保留最后成功账本。持仓除权/分红因子变化时停止更新，要求核对公司行为，避免无声算错收益。

`state/account.json` 是唯一权威账本，包含成交、净值、冰点缓存及逐日事件。CSV是导出，不用于推算账户；不要删除账本或手动改初始资金。

## 本地检查

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m src.run --initialize  # 仅初始化不存在的账本，不会重置已有账本
python -m src.scan              # 扫描最近两个完整交易日
python -m src.run               # 公共行情模拟仓
```

测试使用合成行情验证执行与记账，不构成历史收益回测。真实运行仍需公共行情接口可访问且数据完整。
